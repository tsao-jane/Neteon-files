主秀 1 / 3
第 1 場7/9 · 聊天框Projects

一個記得你工作的助手

目標:每個人當場做出自己的 Project,並學會「列問題 → 逐題答 → 標來源」這招(更完整、更可信)。

現場示範步驟(用業務例子:回客戶詢問)
  1. 先「隨便問」:貼一封客戶來信,叫它回信 → 給出空泛、罐頭味重的版本。
  2. 換成公式 + 完整性招式(見下方指令)→ 同一封信,立刻變得能用,當場對比。
  3. 開一個 Project「My Desk」:設自訂指令(你的語氣、US B2B),上傳產品規格 / datasheet PDF / 幾封你寫過最好的信。
  4. 之後只打「draft a reply to this inquiry」→ 它直接抓對語氣與規格,不用再貼背景。
逐字指令(複製貼上)

Write a reply to this customer email. ← 先用這句示範「不夠好」

You're a sales rep at Neteon (industrial PCs). The customer is a factory-automation integrator. Reply to their email — but FIRST list every question they asked, THEN answer each one, and note which spec or document each answer comes from. Flag anything you're unsure of as "needs checking." Keep it short, professional, US B2B tone.

[Project custom instructions] You are my sales assistant at Neteon. Write in my voice — short, professional, US B2B. Use the product specs and past emails I've uploaded; if something isn't in them, say so instead of guessing.

關鍵台詞

"A prompt is re-explaining yourself every time — a Project is it remembering you: your products, your voice."

"Notice it listed every question first — that's how you stop it answering only half."

換你做 + 分組

每個人開一個自己的 Project,丟一個自己常重複寫的東西進去試一次。分組:各部門聊「我的 Project 該記住什麼背景」。

本場 check-in(蓋章)
填回饋:我建了一個 Project 來做 ___,而且用它做了一次 ___。
換成你的工作

行銷 → 產品文案助手 · 營運 → 回供應商 / 出貨說明 · 客服/行政 → 常見問題、政策回覆。同一招,換你的檔案與語氣。

主秀 2 / 3
第 2 場7/30 · 你的瀏覽器Claude in Chrome

讓 AI 進到你打開的工具裡幫你做事

目標:大家裝好 Claude in Chrome,並用它在一個你打開的 Google Sheet / 網頁上做一件事 —— 重點不是「會比較」(那 chat 就能做),而是它碰得到 chat 碰不到的東西。

先教安裝(3–5 分)
  1. 用 Chrome 或 Edge → Chrome 線上應用程式商店搜「Claude in Chrome」→ Add to Chrome。
  2. 用 Claude 帳號登入(需付費方案)→ 點拼圖圖示釘選 → 第一次給權限時選「Ask before acting」。
  3. 安全提醒:它能點、打字、截圖 —— 只在公開頁面示範,別碰登入的內部系統或客戶個資。
關鍵觀念:Claude in Chrome 厲害在哪

不是「會比較」(那普通 chat 就能做)。重點是它能直接看、操作你瀏覽器裡的東西 —— 你打開的 Google Sheet、你登入的 CRM / 入口網站、一個不好複製的網頁。這些都是 chat 碰不到的(你得整段複製貼上)。所以 demo 要演「它進到你的工具裡做事」,而不是又一個 chat 也能做的比較。

現場示範步驟(用業務例子:在 Google Sheet 上選型)
  1. 事先開好一張 Google Sheet:A 欄列候選機型(POC-700、POC-766AWP、Nuvo-11000、RUC-1000D —— 來自 category page 的 In-Vehicle 那格),最上面一列寫客戶需求。
  2. 就在那張 sheet 上,開 Claude in Chrome 側欄。
  3. 叫它讀 sheet 裡的機型 + 客戶需求,把比較欄位 + 優劣 + 推薦整理出來(用「動作前先問」逐步填回 sheet,或讓它產出你貼回)。
  4. 強調:你沒有把任何東西貼進聊天框 —— 它直接在你開的 sheet 裡工作。
逐字指令(複製貼上)

Read the candidate models and the customer's requirements in this Google Sheet. For each model, fill in columns comparing the specs that matter for this customer, add a short pros/cons note and a fit rating, and recommend one — explain why in two sentences. Ask me before changing any cells.

For any spec that's missing, open that model's product page to find it and tell me which page you got it from. Flag anything you can't confirm instead of guessing.

關鍵台詞

"I didn't paste any specs into a chat — it's working inside the Google Sheet I've got open. That's the bit plain chat can't reach."

換你做 + 分組

每個人挑一個你平常在用的 Google Sheet,或一個你登入的網頁工具,讓 Claude in Chrome 在上面幫你做一件事。分組聊「我哪個表單 / 後台最值得讓它進去幫忙」。

穩定度備案:在 Google Sheet 上「直接填回去」是用瀏覽器操作,偶爾會卡 —— 備案是讓它讀 sheet → 產出填好的比較,你再貼回;或全程用「動作前先問」一步步確認。

本場 check-in(蓋章)
填回饋:我讓 Claude in Chrome 在我的 ___(Google Sheet / 網頁)上幫我 ___(附截圖更好)。
換成你的工作

行銷 → 在內容行事曆 sheet 上整理 · 營運 → 在訂單 / 庫存 sheet 上抓重點 · 任何人 → 讓它讀你登入的某個後台、幫你摘要或填表。

第 3 場8/13 · 你的電腦由你示範,不要求動手

把第 2 場的比較,變成存進電腦的成品檔

目標:延續第 2 場 —— 你在 Google Sheet 上做好的選型比較,讓 Claude 整理成一份乾淨的檔案、存進你的電腦。reach 從瀏覽器 / Sheet(S2)再下到你的電腦(S3)。由你示範、不要求動手。

事前(只有你要設定)

用 Claude 桌面版 + 檔案系統連接器,授權一個資料夾;把第 2 場那張 Google Sheet 下載成 CSV(File → Download → CSV)丟進去當素材(非機密)。

現場示範步驟(由你操作)
  1. 承接第 2 場:把那張選型比較(從 Google Sheet 下載的 CSV)放進授權資料夾。
  2. 叫 Claude 讀它 → 整理成一份客戶可看的成品(乾淨的比較 + 兩句推薦),存成 recommendation.md 與 comparison.csv 放回資料夾。
  3. 打開資料夾 —— 成品檔在你電腦裡了,可以直接寄客戶 / 歸檔,不是只停在瀏覽器。
  4. 點一句:「再往上,它還能接 NetSuite、設成每週自動跑 —— 那是西岸進階場;今天先看可能性。」
逐字指令(複製貼上)

Read the comparison CSV in this folder. Turn it into a clean, customer-ready model recommendation — a tidy comparison plus a two-line recommendation — and save it as recommendation.md and a cleaned comparison.csv in this folder. Tell me the file paths, and flag anything you're unsure of instead of guessing.

關鍵台詞

"In Session 2 it worked inside my Google Sheet; now it's dropped the finished file on my computer — ready to attach to an email or file in our drive. That's the partner part."

收尾

開放自願分享:這三場裡你最得意的一個 AI 成果(不評分、不排名)。然後填最後一份 check-in。

本場 check-in(蓋章)
填回饋:這三場裡我最有感 / 之後最想用的一招是 ___。
換成你的工作

任何人 → 整理一疊報價 / 會議記錄 / datasheet → 產出一份檔案 · 需要連系統 / 自動化的人(出貨提醒、報表、排程)→ 報名西岸 MCP 進階場。

每場都要做的一件事

教大家「信任但查證」

驗證,每場順帶示範一次

三場都帶同一個習慣:叫 AI 「標出每個答案的來源 / 哪條規格」、「沒把握就說不確定」, 然後人工抽查。尤其客戶要看的東西,絕不未經檢查就直接送出。這比任何單一功能都重要 —— 也是新手最該帶走的安心感。

東岸要準備的:① 一封真實(去識別化)客戶來信當 S1 教材;② 一個客戶情境 + 對應 category page 子分類的候選機型產品頁(例:In-Vehicle 那組 POC-700 / POC-766AWP / Nuvo-11000 / RUC-1000D)當 S2 教材; ③ 把第 2 場的 Google Sheet 下載成 CSV、放進一個授權資料夾,並先設好 Claude 桌面版/檔案系統連接器,當 S3 教材。三場都先自己跑過一次、錄影、把範本與 check-in 表單放共用頻道(看重播也能蓋章)。
