So what is Cowork?

You hand it a job. It works through the steps. You get files back.

Chat

You ask, it answers.

Claude in Chrome

It reads the page you already have open.

Cowork

It does the job and hands you the result.

What's different about it
1

It works on your computer. Reads and writes your files, no uploading and downloading.

2

What comes out is a real file. Excel with formulas that work, PowerPoint, Word — not a wall of text in a chat window.

3

It runs multiple steps on its own. Describe the outcome, come back to the result.

4

It pairs with Claude in Chrome — last session's browser skill, working inside this.

Before we go further

It still needs you for four things.

A goal

It doesn't decide what's worth doing.

The data

It can only work from what you give it access to.

Permission

Every system it touches, you approved.

Your review

What it produces is a first version, not a final one.

It's handing over a job, not asking a question.

When to reach for it

Is there a file at either end?

Open Cowork

  • It starts from files you already have
  • What you need back is a file, not an answer
  • You'd be opening several files to do it by hand

Just use Chat

  • You want an answer or a second opinion
  • Nothing goes in, nothing comes out
  • You just need to know something

If the answer is “just send me the file,” that's a Cowork job.

The other question

“I already have a folder. Why a project?”

Doing it once

Just point Cowork at the folder. You don't need a project at all.

Doing it every week

Make it a project. That's what the wrapper is for.

1

Instructions apply themselves. You stop saying "read the rules file first."

2

It remembers. Correct it once and you don't correct it again. A folder can't do that.

3

Several sources at once. Folders in different places, reference links, plus your Chat Project.

Before you use anything it makes

How to check what it hands you.

  • Did it actually use the material I gave it?
  • Did it flag what it wasn't sure about?
  • Can I tell the facts apart from the assumptions?
  • Have I checked the numbers, specs and part codes against the source?
  • Could this go out as-is, or what still needs changing?

It can prepare the work. It can't be accountable for it.

Attachment one

Skills

A skill is writing down how you always do something — once.

A prompt

A one-off request. You type it again next time.

A skill

The SOP. Every run after that follows the same standard.

Two ways to make one

Neither involves writing a file.

A  ·  Tell it

In chat, say "here's how I always do X — turn that into a skill." It asks you questions and writes the whole thing.

B  ·  Show it

Record yourself doing the task — screen, clicks, talking out loud. It drafts the skill from the recording for you to approve.

You don't have to write anything. Just record yourself doing the thing.

Where to switch them on

The one setup trip

Settings › Capabilities › Skills

Set it once on your account and it works in Chat and in Cowork. Not two setups.
