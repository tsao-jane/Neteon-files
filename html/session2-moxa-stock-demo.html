Process

Keep the live demo small.

1

Open the Sheet with product models.

2

Open Moxa eOrder Stock Check.

Search exact model and add to list.

4

Read final Stock Check table once.

Preview, approve, write, verify.

Recommendation: run 3 models live. The same process applies to every remaining model.

Prompt 1

Extract from portal. Preview only.

Go to the Moxa Order Management portal: https://eorder.moxa.com/Order/StockCheck.asp I am already logged in. Pull stock data for these exact models: - MGate 5118-T - SDS-G3008 - MDS-G4012 For each model: 1. Start a new search. 2. Type the model into "Model Keyword". 3. Search. 4. Select only the row whose Model column is an exact match. 5. Add it to Stock Check List. 6. Continue selecting product. Rules: - Pick only the exact model listed. - Do not select temperature-rated, Layer 3, or other suffixed variants unless they exactly match my list. - If the full model returns no result, retry with a shorter distinctive fragment, then choose only the exact match. - Tell me which models needed a shorter search. - If a model cannot be found, leave it out and flag it. - Do not substitute a similar model. After all found models are added, read the final Stock Check table once. Preview the extracted data first. Do not write to Google Sheet yet.
Prompt 2

Write to Sheet after approval.

Use the Google Sheet tab I have open. Before writing, confirm which Sheet and tab you are using. Write the previewed stock check results into these columns: - Part#/Model Spec - Current Available Qty - Stock Available on date (1) - Qty on date (1) - Stock Available on date (2) - Qty on date (2) - Taiwan Current Available Qty - Standard Lead Time - MRP Other (Qty <= 3pcs) - MRP Other (Qty >= 4pcs) - MRP End User (Qty <= 3pcs) - MRP End User (Qty >= 4pcs) Important: The two "Stock Available on date" fields in the portal show a date on top and quantity underneath. Keep date and quantity separate. Do not hardcode dates into headers. If no date is shown, put N/A for the date and record the quantity as displayed. After writing: 1. Bold and freeze the header row. 2. Read the rows back from the Sheet. 3. Verify the data matches the preview. 4. Give me a short summary of items actually in stock and any unusually long lead times.
