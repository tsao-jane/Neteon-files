Prompt formula ①

RACE — for a solid, complete ask

R
Role 角色
Who Claude should be — e.g. "a senior IPC sales engineer."
A
Action 行動
The exact task — e.g. "draft a reply to this inquiry."
C
Context 背景
Background & why — who we are, which vendors, what the customer sent.
E
Expectation 期望
Show the desired output: Asked / Missing / Reply. Verify specs, flag unknowns, and ask only quote-blocking questions.
Prompt formula ②

RTF — the simplest all-purpose one

R
Role 角色
Set who the AI is.
T
Task 任務
One clear instruction.
F
Format 格式
How to lay it out — email, table, bullet list, Markdown.

Project mindset

A Project is a workspace for repeatable work

① Instructions

How it should think: sales perspective, verify specs, flag unknowns, ask useful questions.

② Knowledge

Datasheets, product pages, price lists, vendor notes, and your own internal context.

③ Workflow

Analyze first, then turn the analysis into sales output: tables, talking points, emails, proposals.

The goal is not one clever prompt. The goal is a workflow the team can reuse.

The prompt that teaches the workflow
You are a senior industrial computer sales engineer at Neteon. I uploaded datasheets for two product options: - Cincoze DX-1300 - Neousys Nuvo-11000 Series Compare them from a sales perspective. Use only the uploaded datasheets or provided product pages. If something is unclear, write "Need to confirm" instead of guessing. Create a table with: 1. Product model 2. Key specs that matter for sales 3. Best-fit customer / application 4. Main selling points 5. Possible concerns or limitations 6. Questions we should ask the customer 7. When sales should recommend this model After the table, summarize the recommendation in plain sales language.
The goal is not “which spec is bigger.” The goal is to learn when sales should lead with which product, and what to ask before recommending.

Project thinking

How to think in Projects

Don't start with "what can AI do?" Start with "which workflow keeps repeating?"
1Workflow
2Inputs
3Analyze
4Output
5Human check

① Price updates

Input: old + new price lists
AI does: find price changes, new SKUs, removed SKUs
Output: sales notes + customer impact

② Vendor launch

Input: datasheets, vendor site, similar products
AI does: SWOT, product line focus, comparison
Output: keywords + campaign angles + proposal outline

③ Marketing assets

Input: product page, selling points, target customer
AI does: turn analysis into copy
Output: banner copy, flyer text, landing page, PDF header

④ Form research

Input: form submission + company domain
AI does: company background, industry, news, likely use case
Output: sales brief + reply + discovery questions
