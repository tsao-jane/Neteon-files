Permissions and boundaries

The tab is the steering wheel.

How to steer

  • Claude sees the tab you have open.
  • You steer by switching tabs.
  • It asks before clicking, saving, submitting, or editing.
  • Today uses public pages and a test Sheet only.

Permission rule

  • Start with view / read-only.
  • Use edit only when actually needed.
  • Edit is acceptable for test Sheets, public data, and low-risk fields.
  • Do not give edit access to sensitive systems during practice.

View first. Edit only when needed. Ask before acting. Human review before submit.

Security check 1

Use public or test data only.

Before we let AI read a browser tab, we choose what kind of tab it is allowed to see.

Allowed for this demo

  • Public company webpages.
  • Demo / test Google Sheet.
  • Anonymized inquiry data only.
  • Screenshots or recordings for unstable steps.

Not allowed here

  • Passwords or payment information.
  • Personal data or salary data.
  • Contracts or internal pricing.
  • Private customer history or confidential company records.
Security check 2

View first. Edit only when needed.

Permission setting

  • Default to view / read-only.
  • Give edit only for a test Sheet or low-risk field.
  • Do not give edit access to sensitive systems during practice.

Ask before acting

  • Claude should ask before clicking.
  • Claude should ask before saving or submitting.
  • Claude should ask before changing data.

Human review

  • AI output is a draft.
  • Review before anything enters a system.
  • Review before anything is shared externally.

Core rule: view first, edit only when needed, ask before acting, human review before submit.
